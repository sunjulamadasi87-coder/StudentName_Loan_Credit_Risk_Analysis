# IPL Data Analysis Project (2008–2024)

## Objective
Analyze IPL team performance, player performance, match outcomes, batting, bowling, toss decisions, venues and season trends using Python and Power BI.

## Dataset
The analytical tables are derived from a public IPL 2008–2024 dataset containing 1,095 matches and 260,920 deliveries. The source analysis reports 347,756 total runs, 12,950 wicket events and 37 normalized venues.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook and Power BI Desktop.

## Project Structure
- Dataset/ — cleaned analytical CSV tables
- Python/ — IPL_Data_Analysis.ipynb
- PowerBI/ — DAX measures and dashboard build guide
- Report/ — final project report PDF
- Visualizations/ — 14 required charts

## Main Insights
- Mumbai Indians lead the source analysis with 144 wins.
- Virat Kohli leads batting with 8,014 runs.
- Yuzvendra Chahal leads wicket events with 213.
- AB de Villiers leads Player of the Match awards with 25.
- 2024 has the highest season runs (25,971) and average runs per match (365.79).
- Fielding first after winning the toss is more common and has a higher observed win rate than batting first.
